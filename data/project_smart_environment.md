# Smart Environment Control System (Digital Logic Design Project)



## What it is
The smart environment control system was my project for Digital Logic Design (DLD). It detects the temperature of the environment and turns LED lights on according to the temperature ranges I defined. It can also detect the humidity in the environment. The system uses sensors, LEDs and a buzzer.

## How it works
A temperature sensor measures how hot or cold the surroundings are, and a humidity sensor measures how much moisture is in the air. The system compares the readings with ranges that I set in advance. Depending on which range the temperature falls into, a different LED lights up, so a person can understand the condition of the room at a glance. The buzzer is used as an alert. When the temperature or humidity goes above a limit, the buzzer on.

## Components I used
- Sensors for temperature and humidity 
- LEDs for the different temperature ranges 
- A buzzer for alerts
-  a microcontroller, logic gates, resistors, breadboard


## Why this project fits digital logic design
DLD is about how inputs are turned into outputs through logic. In this project the sensor readings are the inputs, and the LEDs and the buzzer are the outputs. Deciding which output turns on for which input range is a decision-making circuit, which is exactly what logic design teaches. The project showed me how hardware can react to the real world instead of only running on a screen.

## Challenges
The main challange was wiring oon the breadboard as it was mainly related to electrical engineering.

## What I learned
I learned how sensors are connected to a circuit, how to define thresholds, and how to test hardware step by step. 

## Possible improvements
The system could show the readings on a display, send an alert to a phone or switch a fan on automatically when it gets too hot.
