# My Projects Across Computer Science



I have built projects in almost every subject of computer science. Here they are in the order I studied the subjects.

## Digital security locker (Programming Fundamentals, C++)
A digital security locker written in C++. 

## Student management system (Object-Oriented Programming)
A student management system built with object-oriented programming. 

## Smart environment control system (Digital Logic Design)
A hardware project that detects the temperature of the environment and switches LED lights on according to temperature ranges that I defined. It can detect humidity too. It uses sensors, LEDs and a buzzer. 

## Online pet shop and vet system (Database Management Systems, SQL)
An online pet shop and veterinary system built with SQL. 

## RFID intruder detection system (Computer Networks)
A security system that uses RFID to detect an intruder. 

## Flight delay prediction (Data Science, Python)
A project that predicts flight delays using Python. 

## Intruder classification and suspicious activity detection (Deep Learning)
A deep learning project that classifies intruders and detects suspicious activity. 

## RAG for student career anxiety (Cloud Computing)
A retrieval-augmented generation chatbot about student career anxiety. 

## Campus Marketplace (Mobile Application Development, React Native)
A mobile app called Campus Marketplace built with React Native. 

## SentinalGuard (Final Year Project, in progress)
My final year project, still going on. 

## What connects my projects
Many of my projects are about detection, security and helping people: the security locker, the RFID intruder detection, the deep learning intruder classification and now SentinalGuard. This fits my side interest in cyber security and my long term goal of cyber forensics. Other projects, such as the pet shop system, the marketplace app and the career anxiety RAG, show that I enjoy building practical tools in many areas.
